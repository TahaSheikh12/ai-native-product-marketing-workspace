# Start here

This workspace helps you produce better product marketing work without restarting from zero in every AI conversation.

## Five-minute setup

Complete these three files first:

1. `context/product.md` — what the product is, what problem it solves and what evidence exists.
2. `context/audiences.md` — who matters, what they care about and what objections they have.
3. `context/current-priorities.md` — what is in flight right now.

Leave unknown fields blank. Do not invent content simply to complete the templates.

## Optional calibration

Add only what will improve real work:

- `context/operator-profile.md` for your remit, working preferences, communication style and stakeholders.
- `context/competitors.md` for reviewed buyer alternatives and differentiation.
- `context/evidence-register.md` when research or data begins supporting decisions.
- `context/claims-and-proof.md` before producing external-facing claims.

Do not wait for every file to be complete. Start with one real priority and improve the workspace through use.

## Starting a session

Use this prompt:

> Read `WORKSPACE.md` and the relevant files in `context/`. Summarise what you understand, identify any important gaps, and help me with the highest-priority task.

For a specific workflow:

> Read `workflows/README.md`, select the one workflow that owns my primary decision, and explain the choice in one sentence. Use only the analytical skills needed to support it.

For an analytical task:

> Use the `revenue-whitespace-analysis` skill within the appropriate workflow. Confirm the analytical grain, period, revenue definition and comparator before calculating opportunities.

The workflow router is in `workflows/README.md`; the non-overlapping analytical skill catalog is in `skills/README.md`.

Copy-ready prompts are available in `prompts/README.md`. Reusable deliverable structures are listed in `templates/README.md`.

## Ending a session

Before finishing:

1. Save the final deliverable under `outputs/`.
2. Record confirmed decisions in `context/decisions.md`.
3. Update `context/current-priorities.md` if the status changed.
4. Add a short entry to `context/session-log.md`.

Only update durable context after you have reviewed and confirmed it.

## Keeping it healthy

Run `quality/workspace-health-check.md` monthly or before sharing the workspace. If results become generic, contradictory or unreliable, use `TROUBLESHOOTING.md`.
