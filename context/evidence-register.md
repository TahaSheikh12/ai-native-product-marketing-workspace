# Evidence register

Record the sources used for material PMM decisions. This is an index, not a storage location for confidential raw data.

## Evidence status

- **Verified:** provenance and content have been checked.
- **Directional:** useful but limited by sample, method, recency or comparability.
- **Unverified:** captured but not yet checked; do not use as proof.
- **Retired:** no longer current or appropriate.

## Source rules

- Give each material source a stable evidence ID.
- Link claims to evidence IDs rather than copying unsupported numbers into multiple files.
- Preserve collection method, sample and date.
- Record contradictory evidence; do not delete it because it complicates the narrative.
- Retire stale sources rather than silently continuing to use them.
