# Workspace health check

Run monthly, after a major change or before distributing the workspace. Use **Green**, **Amber** or **Red** and record the evidence for each rating.

| Area | Green condition | Rating | Evidence | Action and owner |
|---|---|---|---|---|
| Routing | Every active task maps to one workflow; analytical skills have distinct units | | | |
| Priorities | Current priorities are active, owned and dated | | | |
| Product and audience | Core context is current and contradictions are flagged | | | |
| Evidence | Material findings have evidence IDs, provenance, dates and limitations | | | |
| Claims | External claims have evidence, status, approver and review date | | | |
| Messaging | Messaging source of truth contains only reviewed content | | | |
| Decisions | Confirmed decisions and rationale are recorded | | | |
| Outputs | Deliverables have clear status and owners; obsolete drafts are labelled | | | |
| Automation | Proposed automations have value, access, risk and owner recorded | | | |
| Portability | Cursor, Claude Code and Codex instruction files still point to `WORKSPACE.md` | | | |
| Security | No credentials, personal data or restricted employer material are present | | | |

## Rating guidance

- **Green:** current, traceable and usable without corrective work.
- **Amber:** usable with a known gap and named corrective action.
- **Red:** unreliable, unsafe or likely to produce misleading work.
