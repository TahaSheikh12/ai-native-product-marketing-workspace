# Analytical skills

These skills are MECE by **primary unit of analysis**. Choose the row that matches the thing being analysed, not the desired presentation format.

| Skill | Unit of analysis | Question it owns | Do not use it for |
|---|---|---|---|
| `evidence-synthesis` | Source or observation | What does the available evidence say? | Specialist commercial calculations owned below |
| `segment-opportunity-analysis` | Market, segment or use case | Which external opportunity should we prioritise? | Internal revenue-mix gaps or individual accounts |
| `competitive-analysis` | Competitor or alternative | How do buyer-relevant alternatives compare? | Win-rate diagnosis or unverified feature grids |
| `pricing-packaging-analysis` | Offer, package or price point | How should value, packaging or price be evaluated? | Account targeting or final pricing authority |
| `revenue-whitespace-analysis` | Aggregate product × segment cell | Where is internal revenue or penetration underrepresented? | Market sizing or account-level recommendations |
| `cross-sell-up-sell-analysis` | Account × product | Which existing-customer expansion opportunities merit investigation? | Aggregate portfolio strategy or churn prediction |
| `win-loss-analysis` | Commercial opportunity | What patterns and reasons are associated with wins, losses or no-decisions? | Program attribution or seller performance ranking |
| `performance-measurement` | Initiative × audience/cohort × time | Did a launch, campaign or PMM intervention perform as intended? | Individual opportunity diagnosis or causal claims without design |

## Boundary tests

- If the object is an external **market or segment**, use `segment-opportunity-analysis`; if it is an internal **revenue cell**, use `revenue-whitespace-analysis`; if it is a specific **customer account**, use `cross-sell-up-sell-analysis`.
- If the object is a **competitor or alternative**, use `competitive-analysis`; if the object is a **closed opportunity**, use `win-loss-analysis`.
- If the object is an **offer or price point**, use `pricing-packaging-analysis`; if it is a **program or launch result**, use `performance-measurement`.
- Use `evidence-synthesis` for mixed or unstructured sources, but hand specialist calculations to the skill that owns their unit of analysis.

## Workflow crosswalk

| Workflow | Typical supporting skills |
|---|---|
| Discover opportunity | Evidence synthesis, segment opportunity, competitive, revenue whitespace |
| Define strategy | Evidence synthesis, segment opportunity, competitive, pricing and packaging |
| Activate market | Competitive, evidence synthesis, performance measurement |
| Grow customers | Revenue whitespace, cross-sell/up-sell, evidence synthesis, performance measurement |
| Learn and optimize | Performance measurement, win/loss, evidence synthesis |

Invoke a skill by name, for example:

> Use `revenue-whitespace-analysis` on this revenue file. State the analytical grain and comparator before calculating gaps.

Each skill requires the analysis to distinguish measured facts, directional estimates and missing evidence.
