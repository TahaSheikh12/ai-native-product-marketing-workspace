# PMM starter templates

Use a template only after selecting the workflow that owns the decision. Templates shape an output; they do not replace evidence or analytical skills.

| Template | Use it for | Typical workflow |
|---|---|---|
| `customer-evidence-brief.md` | Planning or synthesising customer evidence | Discover / Learn |
| `opportunity-scorecard.md` | Comparing markets, segments or use cases | Discover |
| `positioning-validation.md` | Testing a proposed positioning direction | Define |
| `launch-readiness-checklist.md` | Coordinating market and field readiness | Activate |
| `expansion-prioritization.md` | Reviewing customer-growth opportunities | Grow |
| `win-loss-interview-guide.md` | Gathering buyer-verified decision evidence | Learn |
| `performance-review.md` | Reviewing results and deciding what changes | Learn |

Copy the relevant template into `outputs/`, add a date to the filename and preserve unknown fields rather than inventing answers.
